Recuperar acesso da Central

Selecione um proprietário existente e defina uma nova senha com pelo menos 12 caracteres. Para criar o primeiro proprietário, use essa opção no campo “Tipo de acesso”.

A ferramenta Python escuta somente neste computador. Senhas de contas novas são guardadas no banco como hash e a senha provisória deve ser trocada no primeiro acesso.
