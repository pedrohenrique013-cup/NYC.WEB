Central de inicialização e preparação desta instalação

Use esta tela antes de operar: confira o banco, prepare-o quando necessário, configure os acessos e só então inicie o sistema. A Central funciona apenas neste computador.

Aguarde a leitura da configuração

A Central está lendo sem alterar os registros.

Quando já há dados no SQLite, a Central salva uma cópia em dados/backups antes das alterações de estrutura. Ela não apaga nem substitui o banco.

2. Criar ou recuperar acessos

Abra o gestor para criar o primeiro Proprietário, contas da plataforma com acesso por empresa e usuários de cada empresa. A senha temporária aparece uma vez e precisa ser trocada no primeiro acesso.

O Proprietário tem acesso total, inclusive à Central de Controle. Contas da plataforma ficam limitadas às empresas escolhidas. Usuários de empresa entram no sistema com o código da empresa.

Aguarde a conferência da base.

Recuperar uma conta Proprietário

No gestor, use “Recuperar acesso da Central” para trocar a senha de um Proprietário já existente. Para o primeiro acesso, crie uma conta do tipo Proprietário.

3. Iniciar ou parar o sistema

Verificando o servidor…

O V21.1 abre em http://127.0.0.1:8000. Se aparecer servidor antigo, use “Parar sistema” na Central antiga ou feche o terminal que o iniciou; fechar só a aba não encerra o servidor.
